## 2. Catálogo de Capacidades Técnicas (El Arsenal de 0 a 1)

### 1. Despliegue Rápido de Producto (0 $\to$ 1)
* **De la idea al software funcional en días:** Erradicación del desfase entre Figma y el frontend. Creación directa en código utilizando SvelteKit 2, React, Next.js, TypeScript y Tailwind CSS.
* **Design Systems y UI de Alta Fidelidad:** Tokens de diseño, tipografía cuidada, micro-interacciones, animaciones fluidas y accesibilidad (WCAG) sin inflar los paquetes con librerías pesadas.

### 2. Planos de Control Agénticos y Human-in-the-Loop (HITL)
* **Arquitectura de Bots y Control Remoto:** Interfaces conversacionales en Telegram u otros canales que actúan como plano de control para fundadores.
* **Tool-Calling Estructurado:** Generación de payloads JSON estrictamente validados mediante esquemas (Zod/TypeBox) antes de tocar la base de datos.
* **Aprobación Humana Interactiva:** El agente prepara la mutación de estado, pero un humano aprueba o rechaza con un botón antes de la escritura final.

### 3. Infraestructura Serverless & Edge-First
* **Cloudflare Ecosystem:** Cloudflare Workers, Pages, D1 (SQLite en edge), R2 (almacenamiento de objetos) y KV. Latencia mínima y costo de infraestructura prácticamente nulo en etapas tempranas.
* **Persistencia Relacional y Vectores:** PostgreSQL administrado, Supabase/InsForge, `pgvector` para indexación semántica sin dependencias externas innecesarias.
* **Automatización y Webhooks:** Integración de pasarelas de pago (Hotmart, Stripe), agendas (Cal.com), motores de correo transaccional (Resend) y analítica ligera (Fathom).

### 4. Consultoría en Arquitectura y Diagnóstico de Software
* **Auditoría de Frontend y Rendimiento:** Refactorización de código espagueti hacia arquitecturas limpias, componentes contenedores-presentacionales y reducción drástica de tiempos de carga.
* **Estrategia de Cero Retención de Datos (ZDR):** Diseño de flujos transaccionales donde los datos sensibles viajan cifrados o se descartan tras el procesamiento, reduciendo la superficie de ataque y el riesgo legal.
